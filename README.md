# Routes Vivantes

Plugin WordPress : [`routes-vivantes-declarations`](routes-vivantes-declarations/readme.txt).

Après activation, le formulaire public est sur `/routesvivantes/`.
La carte des signalements est sur `/routesvivantes/admin/` (administrateurs seulement).

La publication d’une nouvelle version (branche `main`, tag ou release GitHub) est décrite dans le readme du plugin.
